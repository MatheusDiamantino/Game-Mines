# Game Mines

Recriação, para estudo, do jogo Mines: um tabuleiro 3x3 com minas escondidas, feito em JavaScript puro.

🔗 **Jogar:** https://matheusdiamantino.github.io/Game-Mines/

## O que foi praticado

- Geração do tabuleiro e sorteio das minas com JavaScript
- Manipulação do DOM e eventos de clique
- Cartas que viram com CSS e modal de vitória ou derrota
- Botão para reiniciar a partida

## Como jogar

Abra o `index.html` no navegador. Encontre 3 dinheiros sem clicar em uma das 3 minas.
